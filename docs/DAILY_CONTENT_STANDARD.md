# Daily inventory quality specification — V2

The existing game remains clue-target unscrambling. Correct target completes; valid alternative anagrams consume an attempt and are explicitly recognized; malformed/nondictionary guesses do not consume attempts. Failure must remain reachable through distinct valid wrong anagrams. No numerical game score is introduced; attempt limits and existing reducer semantics are unchanged.

A distinct puzzle has a normalized signature: sorted lowercase display letters plus the sorted, deduplicated exhaustive full-length dictionary solution set. The validator additionally rejects any repeated letter multiset alone, target answer, stable content ID or clue across inventories. Reordering letters, dates, answers or metadata cannot inflate the count. Inflection variants with a different multiset are not automatically identical, but editorial selection avoids relying on a run of simple plural variants.

All targets use 4–8 lowercase ASCII letters, familiar senses and original clues of 20–180 characters. No answer substring may appear in its clue. The displayed letters are deterministically reversed and must differ from the target. Accepted anagrams derive only from the unchanged production dictionary; no external word list is used. Three to six attempts are set from available wrong-anagram count, so loss is reachable. Selected V2 groups contain at least four dictionary anagrams and no more than nine. Potentially offensive accepted words are screened by a conservative denylist and an AI editorial pass; this is not a claim that an automated list detects every cultural/contextual concern.

Planning difficulty is transparent: easy=4–5 target letters, medium=6, hard=7–8. All targets have direct clues; length is a planning proxy, not empirically calibrated player difficulty. V2 includes 30 easy, 40 medium and 20 hard, interleaved in deterministic nine-day blocks. Original seven keep their original difficulty and attempts regardless of this new authoring rubric.

Source: tools/daily/content/inventory-v2-authored.json contains 90 AI-authored target/clue choices. The assistant reviewed each authored target and clue for ordinary meaning and answer leakage; no independent human editorial review is claimed. Anagrams, signatures, lengths, attempt limits and dates are machine-validated. The generated maintainer report includes every answer and accepted alternative for owner review; it is not public page metadata.

Generate with node tools/daily/build-inventory-v2.js --write, then validate/build/test. Published content and date assignments must be immutable: do not regenerate a published inventory with edited inputs. Future content belongs in a new version/batch with a future cutover and a separate immutable fingerprint. Failures must abort, never silently drop records to reach a passing count.
